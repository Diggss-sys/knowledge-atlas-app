3. Team Run (Dry Run Study)

We're testing whether the room study runs well on everyone's machine before we go further. You don't need Unity, git, or any setup — just download an app, do one short session as a participant, and send back the files it saves. (~5 minutes)

Status: ready — the Windows build is verified and available below.

1. Get the app

  • Windows: Download for Windows (.zip, 132 MB)
    Extract, double-click KnowledgeAtlasStudy.exe. Windows may warn "Windows protected your PC" — click More info → Run anyway.
  • Mac (universal — Apple Silicon + Intel): Download for Mac (.zip, 141 MB)
    Unzip. It's unsigned, so the first launch is blocked — the reliable way in: double-click once and dismiss the warning, then System Settings → Privacy & Security → scroll down → "Open Anyway". (Still stuck? Terminal: xattr -cr then drag the app in, Enter.) Launch is verified (a real M3 Air session produced valid data) and a Mac performance tier has since been shipped, but post-fix performance has not yet been re-tested on real hardware — that's exactly what your run tells us. Please include your macOS version.

2. Do one session (about 3–4 minutes)

  1. Participant ID: type anything memorable — your initials + a number is perfect (e.g. MJ7). Click Begin.
  2. Instructions → Start.
  3. For each of the 4 rooms:
    • Click Enter room.
    • Walk around with W A S D, look with the mouse. Take 15–30 seconds, don't rush.
    • Press Esc to leave.
    • Answer the one question (1–7).
  4. Session complete.

3. Send us your files

On the final screen, click Open results folder. You'll see three files that start with response- (a .csv, a .jsonl, and a .perf.csv). Send all three in the team chat, and tell us:

  • which machine you used (e.g. "M2 MacBook Air", "gaming PC with RTX 3070").

What we're actually checking

The .perf.csv quietly recorded the frame rate while you walked each room — this tells us whether the app runs smoothly on your hardware and whether it runs equally smoothly in every room.

If something goes wrong

  • Black screen / nothing renders: note your machine and tell us. Don't force it.
  • Can't move in a room: click inside the window first so it has focus, then W A S D.
  • Stuck in a room: press Esc.
  • "Where are my files?": the Open results folder button on the last screen opens them for you.
    (Windows: %USERPROFILE%\AppData\LocalLow\COGS 160 Research Lab\Room Studio\, Mac: ~/Library/Application Support/COGS 160 Research Lab/Room Studio/)
