1. Installation Guide

Because the core engine is built in Unity HDRP, the installation process differs significantly depending on your operating system.

Branch note. Until PR #2 merges, Diggss-sys-branch and main do NOT contain the current work. Check out paco/ui-foundation to get everything. This note disappears after the merge.

For Mac Users (M1/M2 — yes, your MacBook runs it)

Run the Unity project from source. The scene is light enough for Apple Silicon. ~30 minutes the first time, almost all of it Unity importing.
  1. Get collaborator access (ask Diego), then: 
    git clone https://github.com/Diggss-sys/knowledge-atlas-app.git
git checkout paco/ui-foundation
  2. Install Unity Hub (Apple Silicon version), free Personal license.
  3. Install exactly Unity 6000.3.16f1 (use the download archive if the Hub doesn't list it).
  4. Open the unity/ folder; wait out the first import (10–20 min).
  5. Run RoomGen ▸ Fetch CC0 Materials once (real textures; needs internet).
  6. Open Assets/RoomGen/Scenes/RoomStudio.unity and press Play.

Contracts-only contributors (schemas, fixtures, validators) can skip Unity: Python 3.10+, then pytest tests -q.

For Windows Users

Fastest path: the built app. Ask Paco for the current RoomStudio.exe folder — double-click, "Load KA spec pair", "Walk control". WASD + mouse, Tab switches condition, Esc exits.

To run from source instead, follow the Mac steps above (skip the Apple Silicon notes).

Mac .app — one volunteer needed

The macOS build target exists (RoomGen ▸ Build macOS Application) but nobody has smoke-tested a .app on real hardware. First M2 owner to build it and report unlocks a no-Unity install for every Mac on the team.

Full guide with troubleshooting: docs/GETTING_STARTED.md
