1. Installation Guide

Because the core engine is built in Unity HDRP, the installation process differs significantly depending on your operating system.

For Mac Users

No Unity Required. You do not need to install Unity or the Unity Hub. You interact strictly with the Python contracts, schemas, and fixtures.
  1. Ensure you have Python 3.10+ and Git installed.
  2. Clone the repository and checkout the integration branch: 
    git clone <repo-url>
git checkout Diggss-sys-branch
  3. Install the Python dependencies: 
    pip install -r requirements.txt
  4. Run the validation tests to verify your environment: 
    pytest tests -q
    (You should see all tests pass green).

For Windows Users

Unity HDRP Environment. You will run the generative engine and VR scaffolding.
  1. Clone the repository and checkout Diggss-sys-branch.
  2. Install Unity Hub.
  3. Through Unity Hub, install exactly Unity 6000.3.16f1.
  4. Open the unity/ directory as your project. (Wait for packages to resolve).
  5. Run the menu command: RoomGen ▸ Bootstrap Project (Run this once).
  6. Press Play. You should see the dining room rendering.
